# Credit Card Fraud Detection

A complete machine learning project for detecting fraudulent credit card transactions.
Built for a data analytics interview to demonstrate end-to-end ML workflow skills:
data exploration, feature engineering, model benchmarking, threshold tuning,
business-oriented evaluation, and an interactive HTML dashboard.

**Start here → open `Fraud_Detection.ipynb` in Jupyter for the full interactive walkthrough.**

---

## Python & Runtime

- **Python:** 3.9 or above recommended
- **Install dependencies:**

```bash
pip install -r requirements.txt
```

- **Notebook runtime:** The full notebook runs in approximately 3–6 minutes depending on hardware.
- **Enhanced workflow runtime:** `enhanced_fraud_workflow.py` takes approximately 5–10 minutes
  (Extra Trees with 350 estimators on ~285,000 rows).

---

## Project Files

| File | Purpose |
|---|---|
| `Fraud_Detection.ipynb` | **Primary deliverable.** Step-by-step interactive analysis, modeling, and business insights |
| `enhanced_fraud_workflow.py` | Reusable pipeline script for training, evaluation, and report generation |
| `generate_dashboard.py` | Generates a self-contained HTML results dashboard from output files |
| `creditcard.csv` | Main working dataset (284,807 transactions, 0.172% fraud) |
| `requirements.txt` | Python dependencies |
| `archive/` | Alternative IEEE-CIS fraud dataset (`fraudTrain.csv`, `fraudTest.csv`) downloaded for reference — the main analysis uses `creditcard.csv` |
| `outputs/` | Generated reports, charts, and alert tables |

## Quickstart

### 1. Interactive Notebook (Recommended)

Open `Fraud_Detection.ipynb` in Jupyter Notebook or JupyterLab and run all cells top to bottom.

### 2. Enhanced Workflow Script

```bash
python enhanced_fraud_workflow.py
```

Optional arguments:

```bash
python enhanced_fraud_workflow.py --dataset creditcard.csv --output-dir outputs --top-k 100
```

### 3. Launch the Dashboard

After running the enhanced workflow, generate the interactive HTML dashboard:

```bash
python generate_dashboard.py
```

Then open `outputs/dashboard.html` in your browser.

---

## What This Project Demonstrates

- **Class imbalance handling** — stratified splits, balanced class weights, PR-AUC evaluation
- **Feature engineering** — cyclic time encoding, log/sqrt amount transforms, V-column aggregates
- **Model benchmarking** — Logistic Regression, Random Forest, Extra Trees compared side-by-side
- **Threshold tuning** — validation-based search instead of a fixed 0.50 cutoff
- **Business perspective** — risk-tiered alert ranking, top-k precision/recall for investigation teams
- **Exportable reports** — confusion matrix, benchmark table, score distribution, feature importance

---

## Output Files

Running `enhanced_fraud_workflow.py` creates an `outputs/` folder with:

| File | Description |
|---|---|
| `model_benchmark.csv` | Validation PR-AUC, ROC-AUC, F1 for all 3 candidate models |
| `threshold_search.csv` | F1, precision, recall at 37 threshold values |
| `high_risk_transactions.csv` | Top-100 highest-scored transactions for alert review |
| `confusion_matrix.csv` | True/false positives and negatives on the test set |
| `business_summary.txt` | Winning model, threshold, and all key metrics |
| `score_distribution.png` | Fraud vs legitimate score separation chart |
| `feature_importance.png` | Top 15 feature importances from the winning model |
| `top_feature_importance.csv` | Feature importance values as a CSV |
| `dashboard.html` | Generated by `generate_dashboard.py` — self-contained HTML |
